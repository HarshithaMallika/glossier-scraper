# Glossier Web Scraper

## Overview

This project implements Exercise 1 of the Data Engineer Scraping Test.

The scraper extracts product information from the Glossier Shop All collection and stores the results in CSV format.

The scraper is written in Python and can be executed from the command line.

## Technologies Used

- Python
- Playwright
- BeautifulSoup
- Requests
- CSV
- JSON

## Requirements

Python 3.x is required.
